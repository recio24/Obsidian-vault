## Dónde encontrar estas imágenes:

1. **Cisco NetAcad**: Muchas de estas imágenes están en el material oficial
2. **Documentación de Cisco**: cisco.com tiene diagramas técnicos
3. **Wikipedia**: Artículos sobre cables ethernet, fibra óptica, etc.
4. **Fotografía propia**: Si tienes acceso a equipos reales, las fotos propias son las mejores
5. **Diagramas Lucidchart/Draw.io**: Puedes crear tus propios diagramas

## Formato recomendado para añadirlas en Obsidian:

```markdown
![[nombre_imagen.png]]
```

O con tamaño específico:
```markdown
![[nombre_imagen.png|500]]
```

## Nota importante:
Las marcas `<!-- IMAGEN RECOMENDADA: ... -->` están colocadas exactamente donde cada imagen debería ir en el documento. Solo tienes que guardar las imágenes con nombres descriptivos y reemplazar esos comentarios con la sintaxis de Obsidian.
